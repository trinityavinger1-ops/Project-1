Understanding HTML

HTML, or HyperText Markup Language, provides the structure and meaning of content on the web. Explore the basics, common elements, and useful learning resources in this student project.

Start learning

What is HTML?

HTML uses elements to organize content such as headings, paragraphs, links, images, lists, and forms. Browsers read HTML documents and display their content as web pages. HTML works alongside CSS for presentation and JavaScript for behavior.

Key terms

Element
A piece of HTML content, often made of a start tag, content, and end tag.
Tag
Markup in angle brackets that identifies an element.
Attribute
Additional information written in an element's start tag.
Semantic HTML
Elements that communicate the purpose of content, such as <nav> or <main>.
